# 交易系统 v2.0

## 更新日志（v1.0 → v2.0）

**核心优化**
1. 修复挂单逻辑矛盾，提供3种方案供选择
2. 增加市场环境量化指标（7个维度判断表）
3. 优化止损策略，增加3%缓冲区避免频繁触发
4. 量化"企稳"标准，给出明确判断条件
5. 加入波动率调整机制，高波动降仓
6. 增加胜率和盈亏比统计追踪模板
7. 新增测试验证计划，分3个阶段逐步放大仓位

**关键改进**
- 止损从"跌破分时均线"改为"跌破分时均线3%以上"
- 回踩低吸从"2:30后买"改为"14:00-15:00稳在5日线上方+其他条件"
- 新增环境判断流程：大盘→涨停数→炸板率
- 新增波动率调整：日均振幅>10%降仓一半

## 核心原则

**主力花钱了才进，要死拉着主力一起死。主力没花钱就不进。**

## 一、选股流程

### 1.1 每日盘后复盘（20:00-21:00）

**Step 1：看龙虎榜**
- 打开东方财富/同花顺龙虎榜
- 筛选条件：涨停板、净买入为正、买入金额>卖出金额

**Step 2：识别主力资金**
- 关注知名游资席位（说明有主力在做）：
  - 陈小群（银河大连黄河路）
  - 呼家楼（中信北京远大路）
  - 章盟主、方新侠等
- 计算净买入金额 = 买入金额 - 卖出金额
- 净买入 > 5000万 且 买方席位多于卖方 → 进入观察池

**Step 3：判断板块热度**
- 该票所属板块是否有3只以上涨停？
- 是否为当前主线题材（AI、机器人、新能源等）？
- 板块龙头是谁？该票是龙头还是跟风？

**Step 4：加入观察池**
- 龙头/中军：标记为「2进3候选」
- 二龙头/跟风：标记为「回踩低吸候选」

### 1.2 观察池筛选标准

| 条件 | 2进3候选 | 回踩低吸候选 |
|------|----------|--------------|
| 身份 | 龙头/中军 | 二龙头/跟风 |
| 板块地位 | 板块前2名 | 板块前3-5名 |
| 昨天表现 | 封板早（10点前） | 冲高回落或横盘 |
| 龙虎榜 | 净买入>3000万 | 有主力介入即可 |
| 流通市值 | 50-200亿 | 不限 |

## 二、策略执行

### 2.1 策略一：龙头/中军 2进3

**适用环境**

| 指标 | 好环境(可做) | 一般环境(减仓) | 差环境(空仓) |
|------|-------------|--------------|-------------|
| 涨停数量 | >50只 | 30-50只 | <30只 |
| 跌停数量 | <10只 | 10-20只 | >20只 |
| 大盘指数 | 站稳20日线上 | 20日线附近 | 跌破20日线 |
| 昨日涨停表现 | 今日平均涨幅>3% | 平均涨幅0-3% | 平均涨幅<0% |
| 炸板率 | <20% | 20-35% | >35% |
| 成交量 | 放量(>前5日均量) | 平量 | 缩量 |
| 连板高度 | 有5板以上 | 最高3-4板 | 最高<3板 |

**环境判断流程**
1. 先看大盘：破20日线→总仓位减半
2. 再看涨停数：<30只→只做低吸不做2进3
3. 最后看炸板率：>35%→空仓休息

**板块持续性判断**
- 板块连续2天以上涨停数>3只
- 板块内有连板高度（至少3板）
- 板块龙头不A杀（涨停后次日不是跌停）

**竞价观察（9:15-9:25）**

| 时间 | 观察点 | 判断 |
|------|--------|------|
| 9:15-9:20 | 竞价价格变化 | 涨停→降到5%左右=好信号 |
| 9:20-9:25 | 竞价量能 | 量能要大（换手率>3%） |
| 9:24-9:25 | 最后几秒 | 价格稳住不继续掉=有承接 |

**入场条件（必须全部满足）**
1. 竞价涨停 → 降到3%-7%开盘
2. 竞价量能充足（预估换手率>3%）
3. 昨天封板质量好（10点前封住，封单>1亿）
4. 竞价最后几秒稳住
5. 同板块至少1只票高开

**挂单执行（二选一）**

方案A：保守挂单（推荐新手）
- **挂单位置**：开盘价+0.5%（确保成交）
- **挂单时间**：9:30:05 开盘后观察5秒再挂
- **挂单数量**：试错仓1成 / 正常仓2成
- **优点**：避免追高，安全
- **缺点**：可能错过强势票

方案B：激进挂单（适合有经验）
- **挂单位置**：4%-5%涨幅（在3%-7%开盘中位）
- **挂单时间**：9:24:50 提前挂好
- **挂单数量**：试错仓1成 / 正常仓2成
- **优点**：能成交到目标票
- **缺点**：可能开得低被套

**备选方案：开盘观察法（最稳）**
- 9:30-9:35观察5分钟
- 开盘不掉破开盘价3%，且量能健康→入场
- 入场价：不高于开盘价+2%
- 仓位：正常仓2成

**入场后处理**
| 情况 | 操作 |
|------|------|
| 开盘直接拉升 | 持有，等涨停 |
| 开盘先掉再拉 | 正常，持有 |
| 开盘掉破0% | 警惕，观察1分钟 |
| 跌破分时均线3%以上 | 止损（过滤假跌破） |
| 开盘30分钟内无法站上开盘价 | 考虑减半仓 |

### 2.2 策略二：龙头/二龙头 回踩低吸

**适用环境**
- 轮动快的行情
- 情绪分化阶段
- 主线还没结束

**观察标的**
- 前期板块龙头，已回调2-3天
- 龙虎榜曾有主力介入，主力没跑

**入场条件（必须全部满足）**
1. 回调到5日线或10日线附近（±2%范围内）
2. 缩量（成交量<前5日均量50%）
3. 尾盘企稳信号（满足以下2条以上）：
   - 14:00-15:00价格稳在5日线上方
   - 最后1小时不创新低
   - 14:30后出现小单承接（卖盘减少，买盘增多）
4. 板块内其他票还在活跃（至少1只涨停或涨幅>5%）
5. 大盘环境不差（不在单边下跌）

**执行方式**
- **买入时机**：尾盘2:30后确认企稳再买
- **买入位置**：支撑位附近（5日线/10日线）
- **仓位**：正常仓2成

## 三、仓位管理

### 3.1 总体原则

| 资金量 | 同时持有 | 单票上限 | 试错仓 |
|--------|----------|----------|--------|
| <10万 | 2-3只 | 30% | 10% |
| 10-50万 | 3-4只 | 25% | 10% |
| >50万 | 4-5只 | 20% | 5% |

**波动率调整（重要）**
| 日均振幅 | 基础仓位 | 调整后仓位 | 说明 |
|----------|----------|-----------|------|
| <5% | 2成 | 不变 | 稳健票 |
| 5-10% | 2成 | 不变 | 正常票 |
| >10% | 2成 | 1成 | 高波动降仓 |

**如何判断日均振幅**
- 看最近5天的（最高价-最低价）/收盘价
- 或者简单看：是否经常上演天地板、地天板

### 3.2 加仓规则

**金字塔加仓法**
- 首次建仓：2成（或1成试错）
- 盈利后加仓：1成
- 再次盈利：0.5成
- 总仓位不超过单票上限

**加仓条件**
- 已盈利3%以上
- 趋势明确向上
- 板块热度还在

### 3.3 仓位分配示例（10万资金）

| 场景 | 2进3 | 回踩低吸 | 空仓 |
|------|------|----------|------|
| 情绪好，主线明确 | 3成×2票 | 2成×1票 | 0 |
| 轮动快，不明确 | 1成试错×1票 | 2成×2票 | 3成 |
| 情绪差 | 空仓 | 2成×1票 | 8成 |

## 四、止损止盈

### 4.1 止损规则

| 策略 | 止损条件 | 说明 |
|------|----------|------|
| 2进3 | 跌破分时均线3%以上 | 过滤假跌破，避免被洗 |
| 2进3 | 跌破开盘价5% | 日内硬止损 |
| 2进3 | 收盘跌幅>7% | 承认判断错误，必须清仓 |
| 2进3 | 买入后1天涨幅<3% | 时间止损，换票 |
| 回踩低吸 | 跌破支撑位3% | 承认判断错误 |
| 回踩低吸 | 支撑位横盘3天不涨 | 时间止损 |

**止损执行原则**
1. **硬止损不商量**：收盘跌幅>7%，第二天开盘必须走
2. **软止损看情况**：跌破分时均线3%，观察是否快速收回
3. **时间止损严格执行**：短线不做长线梦，不涨就换

### 4.2 止盈规则

| 情况 | 操作 |
|------|------|
| 涨停 | 持有，看明天 |
| 冲高回落 | 分时均线破位减半仓 |
| 盈利5-10% | 移动止损到成本价 |
| 盈利>10% | 止损移到+5%，锁利润 |

### 4.3 时间止损

- 买入后2天不涨 → 减半仓
- 买入后3天不涨 → 清仓换票
- 短线不做长线梦

## 五、每日执行流程

### 5.1 盘前（9:00-9:15）
- [ ] 查看隔夜消息，判断是否影响持仓
- [ ] 回顾昨天龙虎榜选出的观察池
- [ ] 确定2进3候选（1-3只）
- [ ] 确定回踩低吸候选（1-2只）

### 5.2 竞价（9:15-9:25）
- [ ] 9:15 观察候选票竞价情况
- [ ] 9:20 判断竞价量能是否充足
- [ ] 9:24 决定是否挂单
- [ ] 9:24:50 挂2%买单（如符合条件）

### 5.3 盘中（9:30-15:00）
- [ ] 9:30-9:35 观察开盘走势，判断是否成交
- [ ] 盯持仓票分时，触发止损立即执行
- [ ] 14:30 观察回踩低吸候选是否企稳
- [ ] 14:50 决定是否低吸

### 5.4 盘后（15:00-21:00）
- [ ] 记录今日交易（买卖价格、原因、结果）
- [ ] 复盘今日操作，对错在哪里
- [ ] 17:00后看龙虎榜，更新观察池
- [ ] 制定明日计划

## 七、风控铁律

1. **单日亏损>3%** → 停止交易，休息1天
2. **连续亏损3笔** → 仓位减半，复盘找问题
3. **周亏损>5%** → 停止交易，重新审视系统
4. **不追高**：挂单价不超过3%
5. **不满仓**：永远留后手
6. **不抄底**：抄底等企稳，不猜底

## 八、测试验证计划

### 8.1 模拟测试阶段（第1-2个月）

**测试规则**
- 用模拟盘或小资金（不超过总资金10%）
- 严格按照系统执行，记录每笔交易
- 每周统计一次胜率和盈亏比

**测试目标**
| 指标 | 目标值 | 实际值 | 达成 |
|------|--------|--------|------|
| 2进3胜率 | >40% | ? | ? |
| 回踩低吸胜率 | >50% | ? | ? |
| 总体盈亏比 | >1.5:1 | ? | ? |
| 最大回撤 | <15% | ? | ? |
| 月收益率 | >5% | ? | ? |

**测试通过条件**
- 连续2个月达成目标
- 至少完成30笔交易
- 没有出现重大风控事件（单笔亏损>10%）

### 8.2 实盘小资金阶段（第3-4个月）

**放大到20%资金**
- 继续记录统计
- 重点观察：压力下的执行情况
- 根据实际情况微调参数

### 8.3 正常运行阶段（第5个月起）

**逐步放大到正常仓位**
- 每增加10%仓位，观察1周
- 保持每月统计和复盘
- 遇到回撤立即降仓

### 8.4 需要验证的参数

| 参数 | 当前值 | 验证方法 | 优化方向 |
|------|--------|----------|----------|
| 竞价换手率阈值 | >3% | 统计不同值下的胜率 | 找最优区间 |
| 回踩天数 | 2-3天 | 统计不同天数成功率 | 找最佳天数 |
| 挂单位置 | 4-5%或开盘观察 | 对比两种方式收益率 | 选更优的 |
| 止损幅度 | 3%/5%/7% | 测试不同止损幅度 | 平衡胜率和盈亏比 |

### 8.5 系统迭代机制

**每月底复盘**
1. 统计本月数据，填入统计表
2. 分析亏损交易，找出共性
3. 调整1-2个参数（不要大改）
4. 下月用新参数测试

**禁止行为**
- 不要连续亏损就大改系统
- 不要因为1笔大赚就放松规则
- 不要跳过测试直接放大仓位

## 九、常见问题FAQ

**Q: 如果连续3笔都止损了怎么办？**
A: 停下来，先判断：
- 是市场问题？→ 减仓或空仓
- 是系统问题？→ 记录下来，不要马上改
- 是执行问题？→ 回想是否严格执行

**Q: 2进3总是买不进怎么办？**
A: 说明你的挂单价格太保守，两种选择：
- 改用方案B激进挂单（4-5%）
- 或者改用开盘观察法，等确认再进

**Q: 回踩低吸买进去又跌了怎么办？**
A: 严格止损！不要补仓摊成本。
回踩低吸的止损就是跌破支撑位3%，认错走人。

**Q: 龙虎榜的票第二天一定要买吗？**
A: 不是！观察池≠买入池。
第二天必须符合竞价条件才能买，不符合就放弃。

**Q: 这个系统适合什么市场？**
A: 适合A股的短线生态，不适合：
- 熊市主跌浪（空仓为主）
- 阴跌行情（不做）
- 单边上涨行情（可以放大仓位）
